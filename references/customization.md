# 自定义智能回复指南

本文档介绍如何通过 `config.toml` 配置文件自定义 AI 智能回复的行为。

## 配置项说明

### 1. 客服人设 (`persona`)

定义 AI 的角色和性格。

```toml
persona = "你是一个专业、友好的客服助手。"
```

**更多示例：**

```toml
# 活泼风格
persona = "你是一个热情开朗的客服小姐姐，说话活泼有亲和力。"

# 专业严谨风格
persona = "你是一位资深技术顾问，擅长用通俗易懂的语言解释复杂技术问题。"

# 销售导向
persona = "你是一位经验丰富的销售顾问，善于发现客户需求并推荐合适的方案。"
```

### 2. 业务背景 (`business_context`)

告诉 AI 你是做什么的，这样它能给出更有针对性的回复。

```toml
business_context = "我们是一家设计工作室，主营品牌设计、UI/UX 设计、插画等服务。价格区间 5000-50000 元，周期 1-4 周。"
```

**更多示例：**

```toml
# 电商
business_context = "我们是一家潮流服饰品牌，主打 18-30 岁年轻群体，全国包邮，7 天无理由退换。"

# SaaS
business_context = "我们提供企业级项目管理工具，有免费版、专业版(99元/月)和企业版(定制报价)。"

# 教育
business_context = "我们是一家在线编程教育平台，提供 Python、Java、前端等课程，支持 1v1 辅导。"
```

### 3. 回复规则 (`reply_rules`)

控制 AI 回复的具体行为。每行一条规则。

```toml
reply_rules = """
使用中文回复，语气亲切专业
回复简洁有力，一般 1-3 句话即可
不要使用 emoji
不要自称"我是AI"或"我是机器人"
遇到无法确定的具体信息（如价格、交期），表示会确认后回复，不要编造
如果客户问联系方式，引导在当前窗口沟通
"""
```

**规则定制示例：**

```toml
# 英文客服
reply_rules = """
Reply in English, professional and friendly tone
Keep responses concise, 1-3 sentences
If unsure about pricing or delivery, say you will check and get back
"""

# 严格话术控制
reply_rules = """
首次回复必须先感谢客户
报价时一定要说"具体价格需要根据需求评估"
不允许承诺具体交付时间
遇到投诉类消息，先表示理解和歉意，再询问具体情况
"""
```

### 4. 知识库 (`knowledge_base`)

这是最关键的自定义内容。放入你的产品信息、常见问题、价格体系等，AI 会优先参考这些信息来回复客户。

```toml
knowledge_base = """
Q: 你们的设计服务价格是多少？
A: 根据项目复杂度：Logo 设计 3000-8000 元，品牌全案 10000-50000 元，UI 设计 500-2000 元/页。

Q: 设计周期是多久？
A: Logo 3-5 个工作日，品牌全案 2-4 周，UI 按页面数量 1-3 周。

Q: 可以修改几次？
A: 我们提供无限次修改直到您满意为止。

我们的优势：
- 10 年设计经验
- 服务过 200+ 客户
- 100% 原创设计
- 全额退款保障
"""
```

**知识库组织建议：**

1. **QA 格式**：常见问题用 Q/A 格式最清晰
2. **分类整理**：按产品/服务/售后等分块
3. **具体数据**：包含具体的价格、时间、参数
4. **边界说明**：哪些能做、哪些不能做

**复杂知识库示例：**

```toml
knowledge_base = """
=== 产品线 ===
1. 基础版 - 99元/月，5个用户，10GB 存储
2. 专业版 - 299元/月，20个用户，100GB 存储，API 接口
3. 企业版 - 定制报价，不限用户，私有部署

=== 常见问题 ===
Q: 支持哪些支付方式？
A: 支持微信、支付宝、银行转账。年付享 8 折优惠。

Q: 数据安全如何保障？
A: 采用 AES-256 加密，数据中心通过 ISO 27001 认证，每日自动备份。

Q: 可以免费试用吗？
A: 支持 14 天免费试用，不需要绑定支付方式。

=== 不要回答的问题 ===
- 竞品对比：不要评价竞争对手的产品
- 内部信息：不要透露公司内部流程或员工信息
- 未发布功能：不要承诺或暗示即将推出的功能
"""
```

## 调试和测试

配置完成后，可以用以下命令预览 AI 会收到的完整 system prompt：

```bash
python3 <skill_dir>/scripts/parse_config.py config.toml system_prompt
```

这样可以在启动监控前确认配置效果。
